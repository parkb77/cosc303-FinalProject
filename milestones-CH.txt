PROJECT
A Python application will let a user define a grid, start/goal, and digital
barriers, compute a shortest route, and visualize it. The intended physical
demonstration is a Roomba j8 following that route in an open area. A battery-
powered Raspberry Pi running Raspberry Pi OS is the intended deployment host.
The Clean Base is the existing charging/disposal dock, not an assumed controller.

MY PRIMARY RESPONSIBILITIES
Design and implement the C++ robot API, its connection/telemetry boundary, and
the Python connector that calls it. Coordinate units, commands, failures, and
integration with the partner's simulator. Assist with simulator/UI integration;
maze generation, pathfinding, and primary UI implementation remain partner-led
unless the team explicitly reallocates them.

TECHNICAL DEPENDENCY / EARLY DECISION
Wi-Fi connection, position reporting, and direct steering are separate
capabilities. Exact j8 firmware compatibility, live pose, bumper reporting,
and distance/angle commands have NOT been demonstrated. The first milestone
must establish what this particular robot supports. Proposed movement API:
drive(double distance_m), rotate(double angle_rad). Meters and radians are OUR
contract; raw robot units and coordinate frame require measurement/verification.
